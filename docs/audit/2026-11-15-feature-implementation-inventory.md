# Flash feature implementation inventory

Reviewed 2026-11-15 against `dev` at `0a1be983` and the published branch tips. Status reflects production entry points, platform adapters, persistence and protocol support. The scope is the [original blueprint](../../Project%20Goal%20and%20Blueprint/android-lan-wifi-direct-transfer-app-plan.md), the [deferred-work register](../FUTURE-OPTIMIZATION.md) and the feature plans cited below. Runtime acceptance remains in the [test backlog](../testing/TEST-BACKLOG.md).

The 2026-11-15 follow-up wired desktop direct-transfer recovery after restart and refreshed the affected historical status documents.

## Hub and wider roadmap

- **Push wake-up for sleeping phones.** Announcements already produce local notifications after sync, and Hub call signalling is wired. A content-free OS wake-up adapter for a suspended process remains deferred. The service choice is open. [HR7/HR9](../plans/HUB-READINESS-REMEDIATION.md) · [S-17 proposal](../ENTERPRISE-FEATURE-RECOMMENDATIONS.md#a3-messaging-platform)
- **Device and organisation scope.** One member with several simultaneous devices and an organisation switcher remain parked. HR6 supports replacing one device with another. A standalone private discovery realm with a rotating discovery tag and an admission proof is also still a design. Hub-enrolled offline LAN trust implements a different scope. [FO-09, FO-16 and FO-18](../FUTURE-OPTIMIZATION.md) · [Realm design](../ENTERPRISE-HYBRID-PLAN.md) · [HR5/HR6](../plans/HUB-READINESS-REMEDIATION.md)
- **Independent department presence controls.** Hidden departments already limit who sees online status. A separate switch to hide presence for a department was deferred. [Directory privacy plan](../plans/HUB-DIRECTORY-PRIVACY-PLAN.md) · [Presence rule](../../server/src/main/kotlin/com/transfer/flash/server/directory/OrganizationDirectory.kt#L226)
- **Announcements beyond the current feed.** Required acknowledgement with reports, scheduled publication, file attachments, reactions/comments and sealed department announcements remain proposals. The current feed supports publication, scope, optional expiry and search. HR10 group message sealing does not implement sealed announcements. [FO-19–26](../FUTURE-OPTIMIZATION.md#fo-19fo-26--hub-feature-ideas-not-decided) · [Announcement DTOs](../../core/hub-protocol/src/commonMain/kotlin/com/transfer/flash/core/hubprotocol/rest/AnnouncementDtos.kt)
- **Enterprise integrations and administration.** The recommendations document is a proposal list with a historical baseline. Unbuilt proposals include admin SSO, external SCIM/LDAP/AD provisioning, high availability and multi-tenancy. Other parked proposals include org charts, remote wipe, out-of-office presence, department file drops and expanded head audit/revocation powers. Current scoped admin roles, directory sync between Flash and its Hub, restore validation and operational monitoring cover parts of the list. [Enterprise proposals](../ENTERPRISE-FEATURE-RECOMMENDATIONS.md) · [FO-23–26](../FUTURE-OPTIMIZATION.md#fo-19fo-26--hub-feature-ideas-not-decided) · [HR1–HR11](../plans/HUB-READINESS-REMEDIATION.md)
- **Security follow-ups.** Whole-file Hub database encryption (FO-15b), a strict app-layer no-plaintext fallback rule for keyed binary traffic (FO-29), and a passphrase-derived Linux vault fallback (FO-30) remain deferred. Mailbox payload sealing, TLS transport and Secret Service support already exist. Phone co-signing exists; QR exchange for co-signing remains open. [FO-14/15/29/30](../FUTURE-OPTIMIZATION.md) · [Inbound binary routing](../../core/engine/src/commonMain/kotlin/com/transfer/flash/core/engine/FlashInboundRouter.kt#L379)
- **Phone-to-PC companion and future platforms.** Clipboard sync, phone notification mirroring, phone SMS/call control, media handoff and phone storage browsing are parked. There is no iOS client or Rust transfer-engine implementation in the reviewed product build. SHA-256 stays the documented integrity baseline. BLAKE3 and alternative transports such as QUIC are exploratory work. [FO-31–35](../FUTURE-OPTIMIZATION.md#companion-cluster-fo-31fo-35--clipboard-notifications-messages-calls) · [Transfer transport research](../transfer/TRANSFER-V2-SWARM-AND-MULTIFILE-PLAN.md#7-transport-engine-upgrade) · [Product modules](../../settings.gradle.kts)
